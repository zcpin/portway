# 2026-10-09

## 重新生成 Windows 应用图标（解决桌面/托盘/安装程序图标发虚）

**问题定位**
- 原始设计稿只有 `client/assets/app_icon.png`（256×256），且 `scripts/icongen.go`
  用双线性点采样缩到 16/20/24 —— 三个内点与中间三角孔在 ≤24px 直接糊成一团。
- ICO 各档位全部用 PNG 压缩条目；托盘 ICO 只有 16–64。
- 安装程序 `scripts/installer.iss` 的 `SetupIconFile` 指向
  `client/windows/runner/resources/app_icon.ico`，所以同一个糊图也影响 setup.exe。

**做法**
- 新增 `scripts/generate_app_icon.py`（依赖 Pillow，仅本机生成用）：
  - 轮廓用参数化模型重建：3 个圆盘 + 3 条圆头锥形连接臂（二次贝塞尔 + 外凸）。
    参数由对原稿做 IoU 坐标下降拟合得到，256px 下 IoU ≈ 0.95。
  - 配色不再用单轴线性渐变，改为从源图采样 32×32 二维颜色场后双线性插值
    （原来的单轴拟合在底部节点偏绿）。
  - ≤32px 用模型 + 小尺寸提示（收细连接臂、放大内点）；>32px 直接重采样源图，
    与设计稿逐像素一致。
  - ICO：≤64px 写 32bpp DIB（BITMAPINFOHEADER + AND 掩码），128/256 写 PNG。
- 原始设计稿另存为 `client/assets/icon_source.png`（不加入 pubspec，不随包分发），
  作为唯一设计来源；`app_icon.png` 由它派生。

**关键几何参数（256 坐标空间）**
- 节点圆心 T(192.2, 52.5) / L(54.6, 132.6) / B(196.9, 210.7)，半径 51.5 / 46.5 / 48.1
- 连接臂半宽 21–33（两端锥度不同），外凸量 13.6–15.1
- 内点半径 22，局部「左上浅 → 右下深」对角渐变

**产物**
- 改：`client/windows/runner/resources/app_icon.ico`（16/20/24/32/48/64/128/256）
- 改：`client/assets/tray_icon.ico`、`tray_icon.png`、`app_icon.png`、macOS 图标集
- 新：`client/assets/icon_source.png`、`scripts/generate_app_icon.py`
- 新：`docs/icon-preview-{light,dark}.png`（浅底/深底验收预览）
- README「开发」节新增「应用图标」小节

**备注**：`scripts/icongen.go` 保留未动，但应用图标已不再走它。
色场/几何参数改动后需重跑脚本并肉眼过一遍 `docs/icon-preview-*.png`。
