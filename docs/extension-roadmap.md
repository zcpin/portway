## 约束与兼容

- 保持 Go daemon + Flutter/Riverpod 桌面客户端架构；HTTP 和 WebSocket 继续只在本机使用并校验 token。

## 阶段设计

### 1. 连接状态与诊断

daemon 在隧道生命周期中记录结构化运行状态，保留 `is_running` 表示运行任务是否存活。列表快照附带详细状态，新增 `runtime` 事件同步连接阶段和错误变化。旧客户端仍收到布尔 `status`。客户端展示详细状态，重连不覆盖较新的推送。

测试连接使用待保存的 SSH 配置执行一次有超时的握手，不创建隧道、不保存配置、不修改主机信任。返回耗时和可读错误，并在请求取消后释放连接。

验收：失败重试、重试耗尽、连接成功、停止/重启的状态转换；旧运行不能覆盖新运行；测试连接不写盘且受认证保护；客户端模型、事件及操作回归。

### 2. 多隧道管理

配置增加分组与可缺省的自动启动字段。分组用于客户端筛选；批量动作由 daemon 返回每条隧道结果，允许部分成功并明确显示失败。复制配置生成新名称，保留认证、转发与重连选项。

验收：旧 TOML 行为不变、禁用自动启动的隧道仍可手动启动、热重载保留手动状态、批量异常不掩盖其他结果、复制/筛选不丢字段。

### 3. 配置迁移与恢复

增加完整配置的导出、预览、导入和备份恢复接口及界面。预览显示重名项和将被影响的隧道；确认导入时重新校验并校验当前配置版本，防止预览后的并发修改被覆盖。备份使用 daemon 配置目录下的专用目录和服务端生成的文件名。

验收：非法/超大配置、名称冲突、并发版本变化、备份/写盘失败、路径穿越均保持现有配置；恢复可重现原有字段和隧道运行策略。

### 4. SSH 认证与主机校验体验

认证方式默认为私钥文件，可选择系统 SSH agent。带口令私钥通过独立解锁动作加载到内存；重启 daemon 后重新解锁。指纹预览和信任写入分离，写入前重查指纹，变更指纹需要明确确认。

验收：正确/错误口令、锁定后重新连接、agent 不可用、指纹首次确认/变更/并发变化；敏感内容不进入配置导出和日志。系统服务需要能访问其运行身份下的 agent。

### 5. 更多转发模式

新增转发类型，默认 `local`。反向转发由 SSH 远端监听、本机连接目标；动态代理仅支持 SOCKS5 CONNECT，目标连接由 SSH 服务端发起。跳板链引用已定义 SSH 连接，验证缺失引用与循环。

验收：三种模式的数据双向传输、半关闭、停止释放连接、SOCKS5 非法请求/域名/IPv6、跳板认证失败与取消清理；现有配置与转发测试继续通过。

### 6. 多实例与工作区

保留自动发现，增加显式选择。工作区具有独立配置及发现目录；创建时使用空配置，不借用其他实例的凭据。切换目标关闭旧客户端，并刷新隧道、连接、密钥、日志和设置。

验收：多个可用候选、失效 token、选定实例离线、daemon 重启、工作区路径与名称校验，以及切换期间迟到事件隔离。

### 7. 版本检查与升级

复用 GitHub Release 版本与平台产物。版本比较遵循语义版本并区分发布渠道，下载后验证对应 SHA256 文件。升级由运行目录外的帮助进程等待程序退出后执行，备份原安装并在替换/启动失败时回滚。用户配置留在原用户目录；不把系统服务安装当作普通便携目录自动覆盖。

验收：版本比较、渠道/平台筛选、下载错误与校验失败、压缩包路径穿越、等待退出超时、替换失败回滚；全部替换测试限定在临时夹具目录。

## 风险与检查点

- 运行状态会跨越异步拨号、重启和 WebSocket 重连，必须绑定到同一次运行并测试并发。
- 配置与运行实例必须一起保持一致；导入/恢复复用事务路径，不能直接覆盖文件后忽略加载错误。
- agent、主机信任与升级具有平台差异；公共逻辑用单元/集成测试，平台分支交由对应构建检查。
- 转发和跳板链会增加连接生命周期复杂度，继续使用统一取消、资源登记和半关闭规则。
- 本次不进行真实 SSH 账户测试、GitHub 发布或当前安装升级；使用本地 SSH 服务、模拟 API 和临时文件验证。
